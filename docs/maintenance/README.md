```powershell
python -B deploy/review_checks.py
python -B -m unittest discover -s deploy -p "test_*.py"
```

CI保留Go单元／vet／模块验证、真实MySQL／Redis race、固定R3实际二进制回退、两前端构建，以及R5契约、C#共享样例、真实依赖／进程恢复和主资产隔离。事件汇总拒绝空测试、缺包完成及意外SKIP。纯文档可明确跳过重任务，未知非文档路径保守触发，gate不把取消或失败当成功。

Go模块最低1.26.0；CI／镜像固定1.27.3。原计划冻结1.25.6／1.27.1；真实扫描确认可达告警后，用户于2026-11-10明确允许必要安全升级例外。只更新修复所需依赖及MVS关联项，保留历史版本和旧失败，不升级gRPC／Protobuf或改写SQL。依赖更新仍按真实可达风险与回归处理。

本机重任务串行，先做轻量验证，再做真实依赖；不足记录ENV_RESOURCE_BLOCKED，不降低1GiB提交／512MiB物理保留线，不修改系统分页或WSL。一次失败先定位，只有源码或环境条件改变后再复测。自动化／真人、模型／真实服务、当前／历史分别记录。
