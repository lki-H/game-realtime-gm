# 工作实战版项目介绍

`game-realtime-gm` 是一个持续迭代中的 Go 游戏后台、GM 运营后台与共斗 PVE 实时服务基础项目。

项目当前重点不是做完整商业游戏，而是在单体 Go 服务中逐步完成玩家账号、JWT 鉴权、PostgreSQL 持久化、Redis 实时状态、WebSocket 长连接、小队房间、PVE 匹配、任务副本、结算、排行榜和 GM 观察审计等后端闭环。

## 技术栈

- Go
- Gin
- PostgreSQL
- Redis
- JWT
- bcrypt
- pgx
- go-redis
- gorilla/websocket
- Docker Compose

## 展示层定位

GM 后台是后端能力的观察窗。

游戏 Demo 是后端能力的验证器。

它们都服务后端主线，不抢主线。
