# 项目简介

这是有限维护的Go游戏业务后端与独立可靠通信实验，面向学习、接口验证和后端项目讲解。可玩合作地下城在后继 [Dungeon Contract](https://github.com/lki-H/dungeon-contract)；两者是同一项目的演进，不在简历中重复计算。

主系统是V2模块化单体：身份、社交与好友房间、招募、匹配提案、Run、共同目标和个人任务、逐人结算、资产账本及GM观察。MySQL保存事实，Redis保存可重建投影，WebSocket连接在进程内。单库所有权锁限制单业务写实例。

React和本仓库Unity客户端用于业务控制／验证；局内事件来自明确受控的本机测试来源，不进行逐帧碰撞、伤害或AI裁决。本仓库不继续增加游戏玩法。

R5为独立模块和四个进程角色，读取隔离恢复副本，提供有限只读RPC和可靠消息报表。主业务不依赖MQ发奖。实验保留独立凭据、最小访问范围、提交后ACK和重复消息去重；当前本机恢复验证不代表跨机器高可用或生产吞吐。

旧legacy模块用于历史兼容和显式回归。它们的进程内状态、旧客户端协议和当时测试不能代替V2能力，也不按目录名批量删除。
