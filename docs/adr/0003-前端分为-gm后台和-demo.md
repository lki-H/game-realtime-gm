# 0003：前端分为 GM 后台和游戏 Demo

## 背景

项目既需要展示管理员运营视角，也需要验证玩家侧实时链路。这两个目标不同，不适合混成一个前端。

## 决策

前端分成两个方向：

```text
frontend/gm-admin：管理员视角
frontend/game-demo：玩家视角
```

## 原因

- GM 后台关注观察、管理和审计。
- 游戏 Demo 关注登录、小队、任务和实时同步。
- 两者共享后端数据，但不共享用户目标。
- 分开后更容易演示，也更容易控制复杂度。

## 暂不采用

- 一个前端同时承担管理员和玩家所有功能。
- 把 GM 后台做成游戏客户端。
- 把 Demo 做成后台管理系统。

## 影响

两个前端可以共享 API 类型、HTTP client、WebSocket 类型、错误码映射和时间格式化，但不强行共享大量 UI 组件。
