# 0005：游戏 Demo 不做完整游戏

## 背景

项目主题是 Go 游戏服务端和 GM 后台，不是客户端游戏开发。

## 决策

游戏 Demo 只做轻量共斗 PVE 演示客户端，用来验证后端实时链路。

## 原因

- Demo 的价值是证明 WebSocket、小队、任务、结算和排行榜可用。
- 完整游戏会引入美术、技能、怪物 AI、碰撞和地图编辑等大量客户端复杂度。
- 轻量 Demo 更适合求职展示和技术演示。

## 暂不采用

- 复杂战斗系统。
- 技能、装备、背包。
- 怪物 AI。
- 地图编辑器。
- 独立完整游戏客户端。

## 影响

Demo V1 只做登录、小队和 WebSocket 消息展示；V2 做任务和结算；V3 再做轻量场景、位置同步和观战视角。
